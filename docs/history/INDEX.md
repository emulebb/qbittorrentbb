# qBittorrentBB Historical Backlog

> **Retired 2026-10-02:** qBittorrentBB is a paused public experiment. This
> backlog is preserved as provenance and has no active issue or project-board
> workflow.

The fork demonstrated a DHT harvester, local SQLite index, DHT Index GUI/RSS,
and Torznab endpoint. The experiment did not become a supported eMuleBB product,
and no further feature evolution is planned. Its matching
`emulebb-libtorrent` fork is paused as well.

The former forward-suite plan is retained in the tooling history:

- [Historical Suite Joint Roadmap](https://github.com/emulebb/emulebb-tooling/blob/main/docs/history/HIST-SUITE-JOINT-ROADMAP.md)

- [Local torrent export and harvest design](../BB-TORRENT-EXPORT-AND-HARVEST.md)
